Use Chrome, Edge or Firefox. In this mode Module 8's forward window draws plain shaded planets instead of mapped ones — browsers block pixel reads on local images. Nothing else differs.

FOR INSTRUCTORS · NEEDS NODE.JS

Run a class

Adds accounts, progress that follows each student to any machine, modules that unlock in order, an instructor roster showing where the class struggled, and a worksheet editor.

StepWhat to do
1Install Node.js (free, ~50 MB) from nodejs.org — take the LTS installer and click through.
2macOS: double-click start-academy.command
Windows: double-click start-academy.bat
Linux: run bash start-academy.sh
3Leave that window open — it is the server. Browse to http://localhost:8080.
4Register your own account first — the first account created becomes the instructor.

First run only: macOS may say "unidentified developer" — right-click the launcher → Open → Open. Windows may show SmartScreen — More info → Run anyway. Both are normal for downloaded scripts.
