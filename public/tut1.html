The big idea: where you release + how fast sets the whole ellipse. Slower than circular → release point = apogee. Faster → perigee. Faster still → escape (≈10.7 km/s from 600 km).
Prograde vs. retrograde: looking down from above the North Pole, Earth spins counter-clockwise. An orbit going the same way (CCW) is prograde; one going the opposite way (CW) is retrograde. Almost everything launched from Earth is prograde — it's cheaper (you get Earth's spin for free).
